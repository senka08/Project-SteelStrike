# Project: Steelstrike

**Project: Steelstrike** — разрабатываемая танковая игра на Godot Engine, вдохновлённая классическими танковыми онлайн-играми.

Игроков ждут знакомая бронетехника, сражения, собственные карты, система повреждений, физика движения и многопользовательский режим.

Проект находится в активной разработке. Основной упор делается на игровой процесс, реалистичное поведение техники и развитие сетевых возможностей.

### Основные особенности
- Танки периода Второй мировой войны.
- Система характеристик и бронирования техники.
- Зоны повреждений и регистрация попаданий.
- Физика движения и анимации техники.
- Собственные игровые карты.
- Ангар, выбор техники и игровой интерфейс.
- Планируемые многопользовательские сражения.

**Engine:** Godot Engine 4  
**Genre:** Tank Action / Multiplayer  
**Status:** In Development
